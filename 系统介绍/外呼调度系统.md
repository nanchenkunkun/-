```
我负责的外呼调度系统，是一个为智能客服场景设计的高并发调度平台
整个系统采用 “水平可扩展的集群架构” 。每个服务实例启动时，都会将自身信息注册到 Redis。任务分配采用轮询算法，均匀分散到所有实例，每个实例独立消费自己的任务队列，实现了无状态设计和负载均衡。
任务的生命周期通过一个五状态机（新建、就绪、运行中、成功、失败）来精确管理。核心调度流程如下：
任务创建：用户通过 OpenAPI 创建任务，持久化到 MySQL。
任务就绪：定时器扫描 MySQL 中的“新建”任务，按轮询策略加载到 Redis 延迟队列（sorted set 结构，以执行时间戳为 score），并更新状态为“就绪”。
任务调度与执行：调度线程从 Redis 中获取到期的任务（score ≤ 当前时间），将其状态改为“运行中”，并触发执行器执行实际的外呼业务。
终态与重试：根据执行结果，任务被标记为“成功”或“失败”。对于失败任务，系统会根据预置的重试策略（如间隔递增）决定是否重新投递回“就绪”队列，保障任务可靠性。
```

我们使用Redis的Sorted Set来实现延时队列，并结合MySQL存储任务详情。任务状态有：新建(new)、就绪(ready)、运行(running)、结束(completed)等。
基本思路：

1. 将任务信息存储到MySQL，状态为“new”。
2. 当任务到达执行时间时，将任务从MySQL中状态为“new”的任务添加到Redis Sorted Set中（同时更新MySQL中任务状态为“ready”），以执行时间的时间戳作为score。
3. 使用一个线程轮询Redis Sorted Set，获取到期的任务（score小于当前时间戳），然后将任务状态改为“running”并执行。
4. 任务执行完成后，将任务状态更新为“completed”或“failed”，并从Redis中删除。

但是，为了避免重复执行和任务丢失，我们需要设计一个可靠的状态转换。

步骤详细设计：

1. 添加任务：
   - 将任务插入MySQL，状态为“new”，并记录计划执行时间。
2. 任务预处理（将任务从MySQL加载到Redis）：
   - 我们可以有一个预处理进程，定期扫描MySQL中状态为“new”且计划执行时间小于等于当前时间的任务，将这些任务添加到Redis Sorted Set中，并将MySQL中的任务状态更新为“ready”。
3. 任务调度（从Redis获取就绪任务）：
   - 调度进程从Redis Sorted Set中获取到期的任务（score小于当前时间戳），然后将任务状态从“ready”改为“running”，并执行任务。
4. 任务执行：
   - 执行任务，根据执行结果更新任务状态为“completed”或“failed”，如果失败且需要重试，可以重新设置执行时间并再次放入Redis（状态重置为“ready”）。
5. 任务重试：
   - 对于失败的任务，如果重试次数未超，可以重新计算执行时间（如延迟一段时间），然后再次放入Redis，并更新MySQL中的状态为“ready”。

注意：为了避免多个调度器同时获取到同一个任务，我们使用Redis的原子操作来获取并移除任务，或者使用数据库的行锁（如select for update）来确保并发安全。

由于Redis的原子操作可以使用Lua脚本，我们可以使用一个Lua脚本来获取并移除到期的任务。

但是，我们也可以使用以下方式：

- 使用ZRANGEBYSCORE获取到期的任务
- 使用ZREM移除这些任务，确保原子性可以通过事务或者Lua脚本。

然而，在分布式环境下，多个调度器可能同时获取到同一批任务，所以我们需要确保每个任务只被一个调度器获取。我们可以使用以下方法：

方案1：使用Redis的分布式锁。
方案2：使用Lua脚本原子性地获取并移除任务，然后将任务分配给调度器。

```
@Component
@Slf4j
public class RedisDelayQueue {
    
    private final RedisTemplate<String, String> redisTemplate;
    private final ObjectMapper objectMapper;
    private static final String QUEUE_NAME = "call_task_delay_queue";
    
    public RedisDelayQueue(RedisTemplate<String, String> redisTemplate, 
                          ObjectMapper objectMapper) {
        this.redisTemplate = redisTemplate;
        this.objectMapper = objectMapper;
    }
    
    /**
     * 添加任务到延时队列
     */
    public boolean addTask(Long taskId, LocalDateTime executeTime, Integer priority) {
        try {
            DelayTask delayTask = new DelayTask(taskId, executeTime, priority);
            String taskJson = objectMapper.writeValueAsString(delayTask);
            
            // 计算score：时间戳 + 优先级调整
            double executeTimestamp = executeTime.atZone(ZoneId.systemDefault()).toEpochSecond();
            double priorityAdjustment = (10 - priority) * 0.001; // 优先级调整
            double score = executeTimestamp - priorityAdjustment;
            
            Boolean result = redisTemplate.opsForZSet().add(QUEUE_NAME, taskJson, score);
            log.info("Added task {} to delay queue, execute at: {}", taskId, executeTime);
            return result != null && result;
            
        } catch (Exception e) {
            log.error("Failed to add task {} to delay queue", taskId, e);
            return false;
        }
    }
    
    /**
     * 获取就绪的任务
     */
    public List<DelayTask> getReadyTasks(int batchSize) {
        try {
            long now = System.currentTimeMillis() / 1000;
            
            // 获取score在0到当前时间之间的任务
            Set<String> taskJsons = redisTemplate.opsForZSet().rangeByScore(
                QUEUE_NAME, 0, now, 0, batchSize);
            
            if (taskJsons == null || taskJsons.isEmpty()) {
                return Collections.emptyList();
            }
            
            List<DelayTask> tasks = new ArrayList<>();
            for (String taskJson : taskJsons) {
                try {
                    DelayTask task = objectMapper.readValue(taskJson, DelayTask.class);
                    tasks.add(task);
                } catch (Exception e) {
                    log.error("Failed to parse task JSON: {}", taskJson, e);
                }
            }
            
            return tasks;
            
        } catch (Exception e) {
            log.error("Failed to get ready tasks from delay queue", e);
            return Collections.emptyList();
        }
    }
    
    /**
     * 从队列中移除任务
     */
    public boolean removeTask(DelayTask task) {
        try {
            String taskJson = objectMapper.writeValueAsString(task);
            Long removed = redisTemplate.opsForZSet().remove(QUEUE_NAME, taskJson);
            return removed != null && removed > 0;
        } catch (Exception e) {
            log.error("Failed to remove task from delay queue", e);
            return false;
        }
    }
    
    /**
     * 批量移除任务
     */
    public void removeTasks(List<DelayTask> tasks) {
        if (tasks.isEmpty()) {
            return;
        }
        
        try {
            List<String> taskJsons = tasks.stream()
                .map(task -> {
                    try {
                        return objectMapper.writeValueAsString(task);
                    } catch (Exception e) {
                        log.error("Failed to serialize task", e);
                        return null;
                    }
                })
                .filter(Objects::nonNull)
                .collect(Collectors.toList());
            
            if (!taskJsons.isEmpty()) {
                redisTemplate.opsForZSet().remove(QUEUE_NAME, taskJsons.toArray());
            }
        } catch (Exception e) {
            log.error("Failed to remove tasks from delay queue", e);
        }
    }
    
    /**
     * 延时任务数据结构
     */
    @Data
    @AllArgsConstructor
    @NoArgsConstructor
    public static class DelayTask {
        private Long taskId;
        private LocalDateTime executeTime;
        private Integer priority;
    }
}
```

## 5. 任务调度服务

```
@Service
@Slf4j
public class CallTaskScheduler {
    
    private final CallTaskRepository taskRepository;
    private final TaskExecutionLogRepository logRepository;
    private final RedisDelayQueue delayQueue;
    private final CallTaskExecutor taskExecutor;
    
    // 调度器配置
    @Value("${scheduler.batch-size:50}")
    private int batchSize;
    
    @Value("${scheduler.poll-interval:1000}")
    private long pollInterval;
    
    private volatile boolean running = false;
    private Thread schedulerThread;
    
    public CallTaskScheduler(CallTaskRepository taskRepository,
                           TaskExecutionLogRepository logRepository,
                           RedisDelayQueue delayQueue,
                           CallTaskExecutor taskExecutor) {
        this.taskRepository = taskRepository;
        this.logRepository = logRepository;
        this.delayQueue = delayQueue;
        this.taskExecutor = taskExecutor;
    }
    
    /**
     * 启动调度器
     */
    @PostConstruct
    public void start() {
        log.info("Starting call task scheduler...");
        running = true;
        schedulerThread = new Thread(this::schedulerLoop, "CallTaskScheduler");
        schedulerThread.setDaemon(true);
        schedulerThread.start();
    }
    
    /**
     * 停止调度器
     */
    @PreDestroy
    public void stop() {
        log.info("Stopping call task scheduler...");
        running = false;
        if (schedulerThread != null) {
            schedulerThread.interrupt();
            try {
                schedulerThread.join(5000);
            } catch (InterruptedException e) {
                Thread.currentThread().interrupt();
            }
        }
    }
    
    /**
     * 调度器主循环
     */
    private void schedulerLoop() {
        while (running && !Thread.currentThread().isInterrupted()) {
            try {
                // 1. 预处理：将新建状态的任务添加到延时队列
                preprocessNewTasks();
                
                // 2. 处理就绪任务
                processReadyTasks();
                
                // 3. 检查超时任务
                checkTimeoutTasks();
                
                Thread.sleep(pollInterval);
                
            } catch (InterruptedException e) {
                Thread.currentThread().interrupt();
                break;
            } catch (Exception e) {
                log.error("Error in scheduler loop", e);
                try {
                    Thread.sleep(pollInterval * 2);
                } catch (InterruptedException ie) {
                    Thread.currentThread().interrupt();
                    break;
                }
            }
        }
        log.info("Call task scheduler stopped");
    }
    
    /**
     * 预处理新建任务
     */
    private void preprocessNewTasks() {
        try {
            List<CallTask> newTasks = taskRepository.findByStatusAndScheduledTimeLessThanEqual(
                TaskStatus.NEW, LocalDateTime.now());
            
            for (CallTask task : newTasks) {
                try {
                    // 添加到延时队列
                    boolean success = delayQueue.addTask(
                        task.getId(), 
                        task.getScheduledTime(), 
                        task.getPriority()
                    );
                    
                    if (success) {
                        // 更新任务状态为就绪
                        taskRepository.updateTaskStatus(task.getId(), TaskStatus.READY);
                        log.info("Preprocessed task {} to READY state", task.getId());
                    }
                } catch (Exception e) {
                    log.error("Failed to preprocess task {}", task.getId(), e);
                }
            }
        } catch (Exception e) {
            log.error("Error in preprocessing new tasks", e);
        }
    }
    
    /**
     * 处理就绪任务
     */
    private void processReadyTasks() {
        try {
            List<RedisDelayQueue.DelayTask> readyTasks = delayQueue.getReadyTasks(batchSize);
            
            for (RedisDelayQueue.DelayTask delayTask : readyTasks) {
                try {
                    Optional<CallTask> taskOpt = taskRepository.findById(delayTask.getTaskId());
                    if (taskOpt.isPresent()) {
                        CallTask task = taskOpt.get();
                        
                        // 检查任务状态是否为就绪
                        if (task.getStatus() == TaskStatus.READY) {
                            // 更新状态为运行中
                            taskRepository.updateTaskStatus(task.getId(), TaskStatus.RUNNING);
                            
                            // 提交给执行器异步执行
                            taskExecutor.executeTask(task);
                            
                            log.info("Started executing task {}", task.getId());
                        }
                        
                        // 从延时队列中移除任务
                        delayQueue.removeTask(delayTask);
                    } else {
                        // 任务不存在，从队列中移除
                        delayQueue.removeTask(delayTask);
                        log.warn("Task {} not found, removed from delay queue", delayTask.getTaskId());
                    }
                } catch (Exception e) {
                    log.error("Failed to process ready task {}", delayTask.getTaskId(), e);
                }
            }
        } catch (Exception e) {
            log.error("Error in processing ready tasks", e);
        }
    }
    
    /**
     * 检查超时任务
     */
    private void checkTimeoutTasks() {
        try {
            // 查找运行中但可能超时的任务
            List<CallTask> runningTasks = taskRepository.findByStatus(TaskStatus.RUNNING);
            LocalDateTime timeoutThreshold = LocalDateTime.now().minusMinutes(5); // 5分钟超时
            
            for (CallTask task : runningTasks) {
                if (task.getUpdatedAt().isBefore(timeoutThreshold)) {
                    log.warn("Task {} timeout, reset to READY state", task.getId());
                    
                    // 重置任务状态为就绪，等待重新调度
                    taskRepository.updateTaskStatus(task.getId(), TaskStatus.READY);
                    
                    // 重新添加到延时队列
                    delayQueue.addTask(task.getId(), LocalDateTime.now(), task.getPriority());
                }
            }
        } catch (Exception e) {
            log.error("Error in checking timeout tasks", e);
        }
    }
    
    /**
     * 手动添加任务
     */
    public boolean addTask(CallTask task) {
        try {
            CallTask savedTask = taskRepository.save(task);
            
            // 如果计划执行时间已到，直接添加到延时队列
            if (task.getScheduledTime().isBefore(LocalDateTime.now())) {
                return delayQueue.addTask(savedTask.getId(), LocalDateTime.now(), task.getPriority());
            } else {
                return delayQueue.addTask(savedTask.getId(), task.getScheduledTime(), task.getPriority());
            }
        } catch (Exception e) {
            log.error("Failed to add task", e);
            return false;
        }
    }
}
```

```
@Service
@Slf4j
public class CallTaskExecutor {
    
    private final CallTaskRepository taskRepository;
    private final TaskExecutionLogRepository logRepository;
    private final RedisDelayQueue delayQueue;
    
    private final ExecutorService executorService = Executors.newFixedThreadPool(10);
    
    public CallTaskExecutor(CallTaskRepository taskRepository,
                          TaskExecutionLogRepository logRepository,
                          RedisDelayQueue delayQueue) {
        this.taskRepository = taskRepository;
        this.logRepository = logRepository;
        this.delayQueue = delayQueue;
    }
    
    /**
     * 执行外呼任务
     */
    public void executeTask(CallTask task) {
        executorService.submit(() -> {
            TaskExecutionLog executionLog = new TaskExecutionLog();
            executionLog.setTaskId(task.getId());
            
            try {
                log.info("Executing call task {} for phone: {}", task.getId(), task.getPhoneNumber());
                
                // 模拟外呼执行逻辑
                boolean success = performCall(task);
                
                if (success) {
                    // 任务执行成功
                    taskRepository.updateTaskStatus(task.getId(), TaskStatus.COMPLETED);
                    executionLog.setExecutionStatus(ExecutionStatus.SUCCESS);
                    
                    log.info("Call task {} completed successfully", task.getId());
                } else {
                    // 任务执行失败，检查重试次数
                    handleTaskFailure(task, executionLog, "Call failed");
                }
                
            } catch (Exception e) {
                log.error("Error executing call task {}", task.getId(), e);
                handleTaskFailure(task, executionLog, e.getMessage());
            } finally {
                // 记录执行日志
                logRepository.save(executionLog);
            }
        });
    }
    
    /**
     * 执行外呼（模拟实现）
     */
    private boolean performCall(CallTask task) {
        try {
            // 这里实现实际的外呼逻辑
            // 例如调用第三方外呼API
            
            // 模拟执行时间
            Thread.sleep(2000 + new Random().nextInt(3000));
            
            // 模拟成功率90%
            return new Random().nextDouble() < 0.9;
            
        } catch (InterruptedException e) {
            Thread.currentThread().interrupt();
            return false;
        } catch (Exception e) {
            log.error("Call execution error for task {}", task.getId(), e);
            return false;
        }
    }
    
    /**
     * 处理任务失败
     */
    private void handleTaskFailure(CallTask task, TaskExecutionLog log, String errorMessage) {
        log.setExecutionStatus(ExecutionStatus.FAILED);
        log.setErrorMessage(errorMessage);
        
        // 更新重试次数
        taskRepository.updateTaskStatusAndRetry(task.getId(), TaskStatus.READY);
        
        Optional<CallTask> currentTask = taskRepository.findById(task.getId());
        if (currentTask.isPresent()) {
            CallTask updatedTask = currentTask.get();
            
            if (updatedTask.getRetryCount() >= updatedTask.getMaxRetries()) {
                // 超过最大重试次数，标记为失败
                taskRepository.updateTaskStatus(task.getId(), TaskStatus.FAILED);
                log.error("Task {} failed after {} retries", task.getId(), updatedTask.getRetryCount());
            } else {
                // 重新调度任务，延时重试
                LocalDateTime retryTime = LocalDateTime.now().plusMinutes(5); // 5分钟后重试
                delayQueue.addTask(task.getId(), retryTime, updatedTask.getPriority());
                log.info("Task {} scheduled for retry {} at {}", 
                        task.getId(), updatedTask.getRetryCount(), retryTime);
            }
        }
    }
    
    @PreDestroy
    public void shutdown() {
        executorService.shutdown();
        try {
            if (!executorService.awaitTermination(60, TimeUnit.SECONDS)) {
                executorService.shutdownNow();
            }
        } catch (InterruptedException e) {
            executorService.shutdownNow();
            Thread.currentThread().interrupt();
        }
    }
}
```

## 系统特点

1. **状态管理**：完整的新建→就绪→运行→结束状态流转
2. **优先级调度**：支持基于优先级的任务调度
3. **重试机制**：自动重试失败任务，可配置重试次数
4. **超时处理**：自动检测和处理超时任务
5. **异步执行**：使用线程池异步执行外呼任务
6. **可靠性**：任务状态持久化到MySQL，Redis用于高效调度
7. **可扩展性**：支持水平扩展，多个调度器实例可以协同工作
